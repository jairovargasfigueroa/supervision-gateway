# Especificaciones de Gateway GraphQL

Una carpeta por funcionalidad: `NNN-nombre/` con `requisitos.md`, `diseno.md` y `tareas.md`. El número coincide con el del plan general (`docs/plan.md` de la carpeta general).

- `requisitos.md`: historia de usuario y criterios de aceptación («CUANDO … ENTONCES …»).
- `diseno.md`: qué cambia en este proyecto y cómo se prueba.
- `tareas.md`: lista de tareas chicas con casillas `- [ ]`; se marcan al terminar cada una.

Si la funcionalidad cruza proyectos, los requisitos y el diseño general están en `docs/specs/` de la carpeta general; aquí va solo la parte de este proyecto.
